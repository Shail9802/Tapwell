# Tapwell 3.1.1 alignment check

Installed the signed release APK over Tapwell on Samsung S21 FE after reconnecting USB. Screenshots were reviewed in both light and dark themes; original dark mode was restored afterward.

The About mark, heading, developer credit, version and link labels share the left content edge. UI hierarchy bounds confirm that the heading, credit, version, “Shail on GitHub” and “View source” all start at x = 72 px on this device. The Close action returns to Settings.

This hotfix only changes the About layout and version metadata. Broader UI review coverage and its limits are recorded in [the 3.1.0 review](ui-review-3.1.0.md). No account, habit, NFC assignment or health data was changed. Screenshots remain in the ignored local build directory because the background Settings screen contains account details.
