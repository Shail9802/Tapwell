# Security reporting

Report vulnerabilities privately to **shailmshah.ss@gmail.com** (Shail Shah). Please do not include real water history, medication names, NFC codes, account tokens or precise location in public issues. A minimal reproduction with synthetic data and the app/Android versions is helpful. Never send passwords or partner access codes.

The developer reviews reports, assesses affected versions and data, contains the issue, prepares a fix and communicates appropriate guidance. No guarantee of a bounty or round-the-clock response is offered. For an incident, evaluate applicable legal, Google and Samsung notification deadlines immediately rather than waiting for the normal privacy-request deadline. Preserve necessary evidence securely and limit access; never place raw sensitive logs in this repository.

The native Samsung SDK is proprietary and must be supplied separately under Samsung's license. Samsung public distribution and write access require approval for the exact package and signing certificate. Access codes and signing keys must never be committed. The default OSS build does not contain Samsung's SDK. Local partner-development builds must not be publicly released before approval.
